# واحة اللسان العربي

تطبيق للأطفال (6–12 سنة) يكتسبون به العربية من محفوظهم: القرآن، والحديث (الصحيحان والأربعون النووية)، والمتون (التحفة، الجزرية، الحسنية، الآجرومية)، والشعر والحكم والقصص. رحلة يومية قصيرة، ورفيق يتكلم، وواحة تكبر مع كل رحلة. يعمل دون إنترنت.

## محتوى المستودع
- `web/` — التطبيق نفسه:
  - `index.html` ملف واحد يحوي الصفحة وكل البيانات، يُبنى من أجزاء المشروع (مشروع Claude «واحة اللسان العربي»: `tools/build_app.py`). لا يُعدَّل يدويًّا.
  - `fonts/` خطوط أميري وتجوّل ورقعة عارف (رخصة SIL OFL)، مقتطعة للعربية واللاتينية.
  - `js/android-shim.js` جسر أندرويد: النطق الآلي بمحرك الجهاز، والمشاركة والحفظ، والطباعة.
  - `hasaniya/` تطبيق «المنظومة الحسنية» كما هو، يُفتح من مربّع «الحسنية» في واحة الطفل (المرحلة الأولى من الدمج).
  - `tests/smoke.js` رحلة طفل كاملة في المتصفح.
- `android/` — غلاف أندرويد (WebView): الميكروفون، والنطق، والمشاركة، وزر الرجوع.
- `desktop/` — نسختا ويندوز ولينكس (Electron).
- `.github/workflows/build-all.yml` — مع كل رفع إلى main: الاختبار، ثم APK موقّع، وويندوز ولينكس، وملفات الويب، وكلها في **Releases**.

## التنزيل والتثبيت
صفحة المستودع ← **Releases** ← أحدث نسخة:
- أندرويد: `waha.apk` (يُسمح بالتثبيت من مصادر غير معروفة مرة واحدة).
- ويندوز: `waha-windows.zip` ← فك الضغط ← `Waha.exe`.
- لينكس: `waha-linux.zip` ← فك الضغط ← `./Waha`.

## مفتاح التوقيع
انظر `SIGNING-AR.md` (مرة واحدة). بدونه تُبنى نسخة تجريبية `waha-debug.apk` لا تُحدَّث فوق النسخة الموقّعة.

## الخصوصية
لا إذن إنترنت في نسخة أندرويد. كل التقدّم والتسجيلات على الجهاز نفسه، وتُنقل بين الأجهزة بملفات التصدير (لوحة ولي الأمر).
